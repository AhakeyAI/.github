# AhaKey Support / 支持入口

如果你在使用、安装、构建或开发 AhaKey 时遇到问题，请按问题类型选择合适的入口。

如果你还不确定应该去哪里，请先查看组织首页：

👉 [`AhaKey Community`](https://github.com/AhakeyAI)

---

## 1. 下载 / 使用官方客户端

如果你只是想下载和使用 AhaKey 官方桌面客户端，请先查看：

👉 [`desktop/releases`](https://github.com/AhakeyAI/desktop/releases)

这里会放官方发布版本、安装包和版本说明。

---

## 2. 官方客户端问题

如果你遇到以下问题，请到 `desktop` 仓库提交 Issue：

👉 [`desktop/issues`](https://github.com/AhakeyAI/desktop/issues)

适合提交 Issue 的情况：

- 客户端无法启动
- 安装失败
- 构建失败
- BLE 连接失败
- 设备无法识别
- 某个功能稳定复现错误
- macOS / Windows 兼容性问题
- 官方客户端文档明显错误

提交问题时，请尽量提供：

- 操作系统：macOS / Windows / Linux
- 系统版本
- AhaKey 设备版本
- 客户端版本
- 问题现象
- 复现步骤
- 截图或日志
- 你期望发生什么
- 实际发生了什么

---

## 3. 协议 / 自己做客户端的问题

如果你在基于 AhaKey BLE 协议开发自己的客户端、工具、脚本或 workflow，请先阅读：

👉 [`protocol`](https://github.com/AhakeyAI/protocol)

如果你遇到协议文档不清楚、命令格式不明确、示例无法运行等问题，请到：

👉 [`protocol/issues`](https://github.com/AhakeyAI/protocol/issues)

提交问题时，请尽量说明：

- 你想实现什么功能
- 当前卡在哪一步
- 使用的系统和开发语言
- 是否参考了官方 `desktop` 或 `examples`
- 是否有日志、截图或 demo

---

## 4. 想法、玩法和共创讨论

如果你还不确定这是不是 bug，或者你只是想讨论一个想法、玩法、workflow、二创方向，请使用 GitHub Discussions：

👉 [`AhaKey Discussions`](https://github.com/orgs/AhakeyAI/discussions)

适合 Discussion 的情况：

- 新功能想法
- AhaKey 使用玩法
- DIY / 二创计划
- 工作流讨论
- 不确定是不是 bug
- 想先和社区讨论方向
- 想发起 Build Log 或共创话题

简单理解：

```text
不确定 → 先 Discussion
明确问题 → 提 Issue
已经改好 → 提 Pull Request
独立作品 → 提到 awesome-ahakey
```

---

## 5. 分享自己的项目

如果你做了独立客户端、工具、脚本、教程、workflow 或桌面 setup，请提交到：

👉 [`awesome-ahakey`](https://github.com/AhakeyAI/awesome-ahakey)

适合提交的内容：

- 第三方客户端
- macOS / Windows 小工具
- Python / Swift / Electron 脚本
- Cursor / Claude / Codex workflow
- OLED / RGB / 配置工具
- 使用教程
- 桌面 setup 展示
- 视频 / 图文教程
- AhaKey 与其他工具的集成方案

---

## 6. 申请固件源码 / 硬件资料

AhaKey 默认开放官方桌面客户端源码、BLE 协议文档、客户端开发示例和社区项目展示入口。

以下资料不默认公开：

- 固件源码
- 硬件原理图、PCB、生产资料
- 官方设备内部实现细节
- 可用于仿制、打板、量产、销售的硬件资料

如果你确实需要访问硬件嵌入式源码或固件资料，请提交申请：

👉 [`AhaKey 硬件源码访问申请表`](https://ahakey.com/cn/hardware-source/apply)

请注意：

- 申请通过不代表可以公开传播或网络分发；
- 不得用于自行打板、仿制、量产、销售或开发竞争性硬件产品；
- 商业硬件合作、OEM、ODM、批量生产、对外销售等情况，需要单独取得书面授权。

---

## 7. 安全问题不要公开发 Issue

如果你发现以下问题，请不要公开发 Issue：

- API Key、Token、私钥、凭证泄露
- 用户隐私数据泄露
- 可导致设备被异常控制的问题
- 可绕过权限、授权或安全限制的问题
- 未授权公开传播固件源码、硬件设计文件或生产资料
- 其他可能影响用户、设备或社区安全的问题

请阅读：

👉 [`SECURITY.md`](https://github.com/AhakeyAI/.github/blob/main/SECURITY.md)

---

## 8. 维护节奏说明

AhaKey 目前由小团队维护，我们会尽量定期查看 Issue、Discussion 和 PR。

请理解：

- 回复可能不会立即发生；
- 信息越完整，问题越容易被定位；
- 大功能或方向性问题可能需要先 Discussion；
- 不适合官方版本的内容，可能会被建议放到 `awesome-ahakey`。

# AhaKey Support

If you need help with using, installing, building, or developing with AhaKey, please choose the right support channel based on your issue.

If you are not sure where to start, please check the organization homepage first:

👉 [`AhaKey Community`](https://github.com/AhakeyAI)

---

## 1. Downloading / using the official client

If you only want to download and use the official AhaKey desktop client, please start here:

👉 [`desktop/releases`](https://github.com/AhakeyAI/desktop/releases)

Official releases, installers, and release notes will be published there.

---

## 2. Official desktop client issues

If you have issues with the official desktop client, please open an Issue in:

👉 [`desktop/issues`](https://github.com/AhakeyAI/desktop/issues)

Use Issues for:

- client startup failures
- installation failures
- build failures
- BLE connection problems
- device detection problems
- reproducible feature bugs
- macOS / Windows compatibility issues
- clear documentation errors

When opening an Issue, please provide:

- Operating system: macOS / Windows / Linux
- OS version
- AhaKey device version
- Client version
- What happened
- Steps to reproduce
- Screenshots or logs
- What you expected
- What actually happened

---

## 3. Protocol / custom client questions

If you are building your own AhaKey client, tool, script, or workflow based on the BLE protocol, please start with:

👉 [`protocol`](https://github.com/AhakeyAI/protocol)

If the protocol documentation is unclear, command formats are confusing, or examples do not work, please open an Issue in:

👉 [`protocol/issues`](https://github.com/AhakeyAI/protocol/issues)

Please include:

- what you are trying to build
- where you are blocked
- your operating system and programming language
- whether you referred to official `desktop` or `examples`
- logs, screenshots, or demo if available

---

## 4. Ideas, workflows, and collaboration discussions

If you are not sure whether something is a bug, or you want to discuss an idea, workflow, remix, or collaboration direction, please use GitHub Discussions:

👉 [`AhaKey Discussions`](https://github.com/orgs/AhakeyAI/discussions)

Use Discussions for:

- feature ideas
- AhaKey workflows
- DIY / remix plans
- workflow discussions
- uncertain questions
- early design discussion
- Build Logs or collaboration topics

Simple rule:

```text
Not sure → Discussion
Clear problem → Issue
Already changed something → Pull Request
Independent project → awesome-ahakey
```

---

## 5. Sharing your own project

If you built an independent client, tool, script, tutorial, workflow, or desktop setup, please submit it to:

👉 [`awesome-ahakey`](https://github.com/AhakeyAI/awesome-ahakey)

You can submit:

- third-party clients
- macOS / Windows tools
- Python / Swift / Electron scripts
- Cursor / Claude / Codex workflows
- OLED / RGB / config tools
- tutorials
- desktop setup showcases
- videos or articles
- integrations with other tools

---

## 6. Requesting firmware source / hardware materials

AhaKey opens the official desktop client source code, BLE protocol documentation, client development examples, and community showcase entry points by default.

The following materials are not public by default:

- firmware source code
- schematics, PCB files, production materials
- internal implementation details
- materials that can be used for cloning, board reproduction, manufacturing, or resale

If you really need firmware or embedded source access, please submit a request:

👉 [`AhaKey Hardware Source Access Request`](https://ahakey.com/cn/hardware-source/apply)

Please note:

- approval does not mean public redistribution is allowed;
- controlled materials may not be used for board reproduction, cloning, manufacturing, resale, or competing hardware development;
- commercial hardware cooperation, OEM, ODM, mass production, or resale requires separate written authorization.

---

## 7. Do not report security issues publicly

Please do not open a public Issue if you find:

- API keys, tokens, private keys, or credential leaks
- user privacy risks
- issues that may allow abnormal device control
- permission, authorization, or security bypasses
- unauthorized public distribution of firmware source, hardware files, or production materials
- other issues that may affect user, device, or community security

Please read:

👉 [`SECURITY.md`](https://github.com/AhakeyAI/.github/blob/main/SECURITY.md)

---

## 8. Maintenance expectations

AhaKey is currently maintained by a small team. We try to review Issues, Discussions, and PRs regularly.

Please understand that:

- replies may not be immediate;
- complete information helps us debug faster;
- large features or direction changes may need Discussion first;
- work that does not fit the official version may be redirected to `awesome-ahakey`.
